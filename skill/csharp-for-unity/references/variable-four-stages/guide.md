# 변수의 네 단계: 선언 · 할당 · 초기화 · 재할당 (Four Stages of a Variable)

교안 4.2 코드를 한 줄씩 실행하며 변수 상자가 빈 공간으로 생기고, 값이 들어가고, 덮어써지는 것을 본다

개념: 01. 변수 · 3.2 · 4.2 · 4.3. 난이도 1/3. 주제: 변수, 선언, 초기화, 재할당, CS0165.

## 배울 것
- `int playerGold;` 직후에는 이름이 붙은 공간만 있고 값은 없다는 것을 "값 없음" 상자로 설명할 수 있다.
- 할당 · 초기화 · 재할당이 같은 상자의 내용물을 바꾸는 일이고, 재할당하면 이전 값이 사라진다는 것을 볼 수 있다.
- 값을 넣지 않은 변수를 읽으면 실행 전에 컴파일 오류(CS0165)로 막힌다는 것을 안다.

## 단계
1. **1. 선언** (`// [1]` 줄): `int playerGold;` 를 실행한 직후다. 메모리에 **playerGold 라는 이름의 int 공간**이 생겼지만 값은 아직 없다 (점선 상자, 값 없음). 이 상태에서 읽으면 컴파일 오류다 (효과 끄기).
2. **2. 할당** (`// [2]` 줄): `playerGold = 10000;` 을 실행한 직후다. 빈 상자에 10000 이 들어갔다. 여기서 `=` 는 "같다" 가 아니라 **"넣어라"** 다.
3. **3. 초기화** (`// [3]` 줄): `int playerLevel = 1;` 을 실행한 직후다. 공간을 만들면서 값까지 한 번에 넣어, playerLevel 상자는 처음부터 값 1 을 가진 채 생겼다.
4. **4. 재할당** (`// [4]` 줄): `playerGold = 5000;` 을 실행한 직후다. 10000 이 들어 있던 상자에 5000 을 **덮어썼다**. 이전 값 10000 은 남지 않는다 (15000 이 아니다).

## 흔한 실수 (효과 끄기)
교안 4.3 의 ❌ 상황: `int experience;` 로 선언만 하고 바로 `Console.WriteLine(experience);` 로 읽었다. C# 은 값을 한 번도 넣지 않은 지역 변수를 읽는 코드를 **컴파일 단계에서 막는다**. 효과 끄기 화면은 읽는 줄(22번)이 빨갛게 표시되고 콘솔에 `CS0165: Use of unassigned local variable 'experience'` 가 찍힌다. 프로그램이 한 줄도 실행되지 않아 앞의 1~16번 줄 출력도 없다.

## 흔한 실수 목록
- **값을 넣지 않은 변수를 읽었더니 CS0165 오류가 난다**: 선언만 한 지역 변수는 값이 정해지지 않은 공간이라 읽을 수 없다. 선언할 때 `int experience = 0;` 처럼 그 상황에서 뜻이 통하는 시작값을 넣어 둔다.
- **재할당했는데 CS0128 오류가 난다**: `int playerGold = 5000;` 처럼 자료형을 또 적으면 같은 이름의 변수를 하나 더 만드는 것이다. 재할당은 자료형 없이 `playerGold = 5000;` 으로 쓴다.
- **`gold = 5000;` 을 했더니 더해지지 않고 5000 이 됐다**: 재할당은 누적이 아니라 갈아 끼우기다. 더하려면 `gold = gold + 5000;` 처럼 지금 값을 오른쪽에서 읽어 계산한다.
- **`playerGold` 와 `playergold` 가 다른 변수로 취급된다**: C# 은 대소문자를 구별한다. 이름이 한 글자만 달라도 "존재하지 않는다" 는 오류가 난다. 지역 변수는 camelCase 로 통일한다.

## Unity 에서는
1. 이 표본은 교안과 같은 콘솔 프로그램(최상위 문)이다. `dotnet new console` 로 프로젝트를 만들고 Program.cs 에 원본을 붙여 넣는다.
2. `dotnet run` 으로 실행해 콘솔 출력을 무대의 콘솔 칸과 비교한다. 입력값이 있으면 무대에서 고른 입력을 그대로 친다.

확인: 콘솔 출력이 무대의 콘솔 칸과 같다.

- Unity 에서는 `Console.WriteLine` 대신 `Debug.Log` 로 찍는다. `Console.ReadLine` 은 Unity 에서 입력을 받지 못한다.
- 최상위 문(클래스와 Main 없이 쓰는 코드)은 Unity 스크립트에 그대로 넣을 수 없다. MonoBehaviour 의 `Start()` 안으로 옮긴다.
